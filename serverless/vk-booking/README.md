# Отправка бронирований в закрытую беседу VK

Функция предназначена для Yandex Cloud Functions. Секреты не хранятся в репозитории.

## Параметры версии функции

- Среда выполнения: Node.js 18 или новее.
- Точка входа: `index.handler`.
- Тайм-аут: 5 секунд.
- Публичный HTTPS-вызов: включён.

## Переменные окружения

- `VK_TOKEN` — ключ доступа сообщества с правом отправки сообщений.
- `VK_PEER_ID` — `2000000095` (закрытая беседа администраторов).
- `ALLOWED_ORIGIN` — адрес сайта без завершающего `/`, например `https://vyacheslavtechnik.github.io`.

После публикации функции её HTTPS-адрес нужно указать в `js/booking-config.js`.

Никогда не добавляйте `VK_TOKEN` в HTML, JavaScript сайта, GitHub Actions или историю Git.
